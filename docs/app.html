The GoTVET desktop app

The PC software reads the catalogue from the GoTVET library and saves papers into Documents\GoTVET\Past Papers.

How it works

  1. This public website is the library you can open on any device.
  2. The Windows installer also starts a local copy of the site at http://127.0.0.1:5088 when you open the app.
  3. In the app, choose Refresh library, then download papers to your Documents folder.

Install from dist/GoTVET-Setup-1.2.0.exe in the GitHub repository, or browse papers here if you are on a phone or tablet.
