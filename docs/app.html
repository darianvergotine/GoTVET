The GoTVET desktop app

The PC software reads the catalogue from the GoTVET library and saves papers into Documents\GoTVET\Past Papers.

Browse papers online View on GitHub

How it works

  1. This public website is the live library. Open it on any phone, tablet or computer.
  2. The Windows app connects to this same site when it starts — it does not open localhost.
  3. Choose Refresh library, then download papers to your Documents folder.
Windows installer
Install from the repository path dist/GoTVET-Setup-1.3.0.exe on GitHub, or browse papers here if you are on a phone or tablet.
